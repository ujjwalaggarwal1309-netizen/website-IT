# Infinity IT Solutions - Enterprise E-Commerce Platform

🌐 **Live Website:** [infinityitsolutions.co.in](https://infinityitsolutions.co.in/)

## About The Project
A fully custom-built Enterprise IT Hardware supplier website. I developed a bespoke WordPress theme from scratch, moving away from bloated page builders to create a highly optimized, lightning-fast B2B platform.

## 🚀 Key Features & Achievements
* **Custom Theme Development:** Built a lightweight, custom WordPress theme using PHP, HTML5, and CSS3 without relying on heavy plugins like Elementor.
* **Technical SEO Mastery:** Engineered custom PHP scripts to dynamically generate Meta Descriptions, enforce `<h2>` hierarchy for 120+ products, and inject OpenGraph tags, achieving a 90+ RankMath SEO score.
* **Automated Data Import:** Created a custom backend system to parse and map Excel data, automatically generating 120+ product pages with their respective categories, images, and OEM part numbers.
* **Security & Performance:** Implemented server-level security headers (HSTS, Referrer-Policy, X-Frame-Options) via `.htaccess` and integrated LiteSpeed Cache minification.

## 💻 Tech Stack
* **Core:** WordPress, PHP 8
* **Frontend:** HTML5, CSS3, JavaScript (ES6), SVG graphics
* **Server/Architecture:** Apache/LiteSpeed, MySQL, custom `.htaccess` routing
