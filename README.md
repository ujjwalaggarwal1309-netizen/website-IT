## About The Project

This repository contains the source code for a fully custom-built Enterprise IT Hardware supplier website. The goal of this project was to move away from bloated visual page builders and develop a bespoke, lightweight WordPress theme from scratch. The result is a highly optimized, lightning-fast B2B platform designed for performance, security, and scalability.

## Key Features

* **Custom Theme Development:** Built a lightweight WordPress theme using raw PHP, HTML5, and CSS3. The architecture completely avoids heavy plugins like Elementor for maximum speed.
* **Technical SEO Mastery:** Engineered custom PHP scripts to dynamically generate Meta Descriptions, enforce proper heading hierarchies for over 120 products, and inject OpenGraph tags. This achieved a near-perfect technical SEO score.
* **Automated Data Pipeline:** Created a custom backend system to parse and map Excel data. This system automatically generates product pages, assigns categories, attaches images, and maps OEM part numbers.
* **Security & Performance:** Implemented strict server-level security headers (HSTS, Referrer-Policy, X-Frame-Options) via custom htaccess routing and integrated advanced cache minification.
* **Schema.org Integration:** Deployed structured JSON-LD data for products and categories to ensure rich snippets in Google Search results.

## Technical Architecture

* **Core:** WordPress, PHP 8.2
* **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6), Custom SVG Graphics
* **Server Environment:** Apache/LiteSpeed, MySQL
* **Performance:** LiteSpeed Cache, CSS/JS Minification, Lazy Loading

## Project Highlights

The codebase reflects modern WordPress development standards:
* **Modular Template Parts:** Code is strictly separated into reusable components.
* **Clean Data Handling:** Custom import scripts handle sanitization and mapping before touching the WordPress database.
* **Accessibility & SEO First:** Semantic HTML and ARIA attributes are used throughout the UI to ensure the site is accessible to all users and web crawlers.
