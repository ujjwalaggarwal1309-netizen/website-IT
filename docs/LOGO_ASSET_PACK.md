# Infinity IT Solutions -- Logo Asset Pack

This document defines the official branding assets for Infinity IT
Solutions.

The logo should be treated as the primary visual identity across the
website, documentation, social media, business stationery, and future
marketing collateral.

# Header Usage

Preferred Format: SVG

Maximum Height: 48px

Always maintain aspect ratio.

------------------------------------------------------------------------

# Footer Usage

Preferred Format: SVG

Maximum Height: 60px

Use the light logo on dark backgrounds.

------------------------------------------------------------------------

# Mobile Usage

Preferred Height: 40px

Use SVG whenever possible.

------------------------------------------------------------------------

# Clear Space

Maintain clear space equal to the height of the letter "I" in the word
"INFINITY" around the logo.

------------------------------------------------------------------------

# Minimum Size

Digital: 120px wide

Print: 30mm wide

Icon: 32px

------------------------------------------------------------------------

# Usage Rules

-   Never stretch the logo.
-   Never rotate the logo.
-   Never recolor the logo.
-   Never add shadows or outlines.
-   Never change proportions.
-   Never place on low-contrast backgrounds.
-   Preserve the approved design.

------------------------------------------------------------------------

-   Use the dark logo on light backgrounds.
